# myla - 아침 주식 포트폴리오 카카오톡 브리핑

매일 아침 7시(KST)에 내 포트폴리오 현재가·등락률·뉴스·투자 아이디어를 정리해서
카카오톡 "나에게 보내기"로 받기 위한 코드/설정입니다.

## 구성

- `portfolio.yaml` - 보유 종목 목록 (국내는 종목코드, 해외는 티커). **실제 보유 종목으로 교체 필요.**
- `scripts/fetch_market_data.py` - `pykrx`(국내), `yfinance`(해외)로 현재가/등락률/평가손익,
  해외 종목 뉴스(yfinance 제공)를 조회해 JSON으로 출력.
- `PROMPT.md` - 매일 아침 자동 실행될 Claude 세션에 전달할 지시문. 국내 종목 뉴스는
  PlayMCP의 네이버 검색 도구로, 메시지 발송은 PlayMCP의 카카오톡 "나챗방" 도구로 처리.
- `output/` - 실행 결과 JSON 백업 (일자별).

## 로컬 실행

```bash
pip install -r requirements.txt
python scripts/fetch_market_data.py
```

## 자동화가 되려면 필요한 것 (사용자가 준비해야 하는 부분)

이 저장소의 코드는 "무엇을, 어떻게" 가져올지에 대한 로직만 담당합니다. 실제로 매일
7시에 카톡이 오게 하려면 아래 두 가지가 **코드가 실행되는 환경**에 준비되어 있어야 합니다.
Claude가 대신 세팅할 수 없는 부분이라 직접 확인이 필요합니다.

### 1. PlayMCP 커넥터 연결 (필수)

PlayMCP는 카카오의 공식 MCP 플랫폼으로, 카카오톡 "나챗방"(나에게 메시지 보내기)과
네이버 검색(뉴스/블로그/쇼핑) 도구를 제공합니다.

1. claude.ai 접속 → 설정(Settings) → Connectors
2. "PlayMCP" 검색 후 연결 → 카카오 계정으로 로그인/OAuth 동의
3. 이 자동화가 돌아갈 프로젝트/환경(채팅)에서 PlayMCP를 "활성화(enabled)" 상태로 켜기

### 2. 실행 환경의 인터넷 아웃바운드 접속

이번 세션(이 GitHub 저장소 작업용 원격 환경)에서 실제로 테스트해보니, 이 환경은
`query1/query2.finance.yahoo.com`(yfinance), `data.krx.co.kr`(pykrx) 로의 외부 접속이
방화벽에 막혀 있어서 가격 데이터를 가져올 수 없었습니다 (`curl: (7) CONNECT tunnel
failed, response 403`). 즉, **지금 이 환경 그대로는 자동화가 동작하지 않습니다.**

- 이 환경("Default")의 네트워크 정책을 인터넷 접속 허용으로 변경하거나,
- 인터넷 접속이 허용된 새 Claude Code 환경을 만들어서 그쪽에서 실행해야 합니다.

환경 네트워크 정책은 https://code.claude.com/docs/en/claude-code-on-the-web 참고.

> 참고: 실행 중 `KRX 로그인 실패: KRX_ID 또는 KRX_PW ...` 메시지가 보일 수 있는데, 이건
> pykrx가 로그인 없이도 되는 일반 시세 조회와 무관한 안내 문구이니 무시해도 됩니다.

### 3. 매일 7시 스케줄 (Claude가 세팅)

위 두 가지가 준비되면, 인터넷 접속이 되고 PlayMCP가 활성화된 환경을 대상으로
`PROMPT.md`의 지시문을 매일 07:00(KST, cron으로는 UTC 22:00) 실행하는 Routine을
만들어 드립니다.

## 아직 필요한 정보

- **실제 보유 종목 리스트**: `portfolio.yaml`은 예시(삼성전자/SK하이닉스/Apple/NVIDIA)로
  채워져 있습니다. 실제 종목코드·티커·수량·평단가로 알려주시면 반영하겠습니다
  (수량/평단가는 선택 사항이며, 없으면 평가손익 없이 현재가/등락률/뉴스만 보내드립니다).
- **PlayMCP 연결 완료 여부**: 위 1번 단계를 완료하시면 알려주세요.
- **메시지를 받을 환경**: 위 2번 네트워크 정책을 바꾸실지, 새 환경을 만드실지 결정해주세요.
